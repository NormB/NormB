# OpenSER and GOES

**Norman Brandinger** · VON, Boston · 2007 · Birds-of-a-Feather session

[**Slides** (PDF, 4 pages)](bof-nbrandinger-openser_and_goes.pdf)

---

A short BOF talk on running OpenSER as the core of a commercial VoIP service.
GOES — Global Online Electronic Services — was an ISP/CLEC selling residential
and SMB VoIP, and the deck makes the case for an open-source SIP proxy as
carrier infrastructure rather than as a lab tool.

Four slides:

| | |
|---|---|
| **OpenSER and GOES** | Who/what/how/why. "OpenSER is the CORE of our VoIP offering." |
| **OpenSER is the Hub** | OpenSER at the center of protocol converters, PSTN, IP PBX, voicemail, system messages and accounting records. |
| **OpenSER Routes the Traffic** | Call flow between Internet, PSTN and customer, with OpenSER inside the GOES network. |
| **OpenSER is the Future** | Contact slide and service roadmap — wholesale, rebranded and prepaid. |

This is the earliest talk in my speaking history and the only one that predates
the OpenSER name being retired: the project split in 2008, with one line
continuing as **Kamailio** and the other as **OpenSIPS**. Both are still the
main focus of my work, so the deck is the front end of a fairly long arc.
